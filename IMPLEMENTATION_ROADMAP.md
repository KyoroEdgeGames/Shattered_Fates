```

? Project compiles without errors
? Main menu appears when game starts
? Play button loads game level
? Cat character is controllable
? HUD displays health/stamina/lives

? Stamina depletes when sprinting
? Lives counter is visible
? Movement states update correctly
? Ability indicators show availability
? Pause menu opens with Escape
? Game pauses when menu is open
? Resume button works
? Restart button reloads level

? Typewriter effect works
? No errors in output log
```
