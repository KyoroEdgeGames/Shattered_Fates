## Game Features

### Player Character
- Play as a cat with unique movement abilities
- 9 lives system
- Wall climbing and jumping
- Pounce attacks
- Stamina-based sprint system

### Core Gameplay
- Inventory management (5 item types)
- Quest system with multiple objective types
- World interaction system
- Save/Load functionality
- Dynamic camera system
